Les règles de la tour

Les étages

Chaque étage de la tour correspond à une tranche de niveaux du guide Duffus, dans l'ordre du guide. On y trouve les donjons et les quêtes de cette tranche, et rien d'autre.

Les 4 catégories

    {%- for info in CATS %}
  • {{ icone(info.icone) }}{{ info.nom }}{{ info.desc }}1 point
    • {%- endfor %}

Une catégorie rapporte 1 point quand elle est complète sur l'étage : tous ses éléments cochés. Chaque grimpeur peut donc rapporter 4 points au maximum par étage.

La jauge et le palier

Les points des grimpeurs actifs remplissent la jauge de l'étage. Le palier à atteindre vaut {{ m }} × le nombre de grimpeurs actifs.

{% if regles.categorie_vide == "offerte" %}

Si une catégorie est vide sur un étage (aucun élément), son point est offert à chacun.

{% else %}

Si une catégorie est vide sur un étage (aucun élément), elle ne compte pas : le palier est réduit à proportion des catégories restantes, arrondi au-dessus.

{% endif %}

Un admin peut aussi fixer le palier à la main, en cas de besoin : la jauge le dit alors.

Les cases, en confiance

On coche soi-même ce qu'on a fait, sans capture d'écran : la case cochée vaut preuve. Chaque coche est inscrite au journal. Tout le monde voit les fiches des autres ; seuls toi et les admins pouvez modifier la tienne.

Le cap de niveau

Chaque étage a un cap : on y joue sans dépasser ce niveau, entre grimpeurs, sans power-leveling. {% if ouvert %}Pour l'étage en cours (étage {{ ouvert.numero }}), le cap est le niveau {{ ouvert.level_cap }}.{% endif %}

L'ouverture de l'étage suivant

Quand la jauge est pleine, un admin vérifie et ouvre l'étage suivant à la main {%- if plancher %}, et pas avant le {{ plancher|date_paris }}{% endif %}. Rien ne s'ouvre tout seul, et le site ne poste rien sur Discord : l'admin annonce lui-même l'ouverture.

La pause et la réintégration

Un admin peut mettre en pause un grimpeur qui décroche : il ne compte plus dans le palier. Il peut continuer à cocher pour rattraper son retard, et ses points comptent de nouveau quand un admin le réintègre. Ces deux décisions sont prises à la main.
